MODUL 1 • DASAR WEBSITE

Kode 1: Belajar HTML dari Nol

Selamat datang di panduan belajar coding OeR. Modul pertama ini ditujukan untuk siapa saja yang ingin membuat website tetapi belum pernah menulis kode. Kamu tidak harus langsung memahami semuanya. Mulailah dengan memahami fungsi setiap bagian, kemudian praktikkan contoh yang tersedia.

1. Apa itu coding?

Coding adalah kegiatan menulis instruksi menggunakan bahasa yang dapat diproses komputer. Instruksi tersebut dapat digunakan untuk membangun website, aplikasi, permainan, dan berbagai perangkat lunak lainnya. Dalam pengembangan website, kita biasanya menggunakan HTML untuk struktur, CSS untuk tampilan, dan JavaScript untuk interaksi.

Bayangkan website seperti sebuah rumah. HTML adalah kerangka dan ruangannya. CSS menjadi cat, dekorasi, dan pengaturan interior. JavaScript membuat sebagian komponen dapat melakukan sesuatu ketika pengunjung menekan tombol atau memasukkan informasi. Ketiga teknologi tersebut bekerja sama membentuk pengalaman website yang utuh.

2. Mengenal HTML

HTML adalah singkatan dari HyperText Markup Language. HTML digunakan untuk menyusun judul, paragraf, gambar, tautan, daftar, formulir, dan konten lainnya. HTML memakai elemen yang umumnya ditulis dengan tag pembuka dan penutup. Contohnya, tag p digunakan untuk paragraf. Tag pembukanya adalah <p> dan tag penutupnya adalah </p>.

3. Membuat file pertama

Buka editor teks. Kamu dapat menggunakan Visual Studio Code atau editor teks lain. Buat file bernama index.html. Perhatikan bahwa nama file harus berakhir dengan .html. Masukkan kode berikut.

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1">
  <title>Website Pertamaku</title>
</head>
<body>
  <h1>Halo, Dunia!</h1>
  <p>Saya sedang belajar coding di OeR.</p>
</body>
</html>

Baris DOCTYPE menyatakan bahwa dokumen memakai HTML modern. Elemen html membungkus seluruh dokumen. Atribut lang="id" memberi tahu browser bahwa bahasa halaman adalah bahasa Indonesia. Bagian head menyimpan informasi dokumen seperti judul tab dan pengaturan karakter. Bagian body memuat konten yang terlihat oleh pengunjung.

Elemen h1 menampilkan judul utama, sedangkan p menampilkan paragraf. Setelah menyimpan file, buka index.html di browser. Kamu seharusnya melihat judul Halo, Dunia! beserta paragraf di bawahnya.

4. Judul, tautan, dan gambar

Gunakan h1 untuk judul utama dan h2 untuk subjudul. Susunan judul yang teratur membantu pembaca memahami isi halaman. Untuk membuat tautan, gunakan elemen a dengan atribut href. Untuk menampilkan gambar, gunakan elemen img dengan atribut src dan alt.

<h1>Belajar Bersama OeR</h1>
<h2>Materi Pertama</h2>
<p>Saya sedang membuat website.</p>

<a href="https://example.com">
  Kunjungi contoh website
</a>

<img src="gambar.jpg"
     alt="Ilustrasi belajar coding">

Atribut href menentukan tujuan tautan. Atribut src menunjukkan lokasi gambar. Atribut alt memberikan deskripsi gambar jika gambar tidak dapat ditampilkan dan membantu pengguna teknologi pembaca layar. Pastikan nama file gambar benar dan file tersebut memang tersedia pada lokasi yang ditentukan.

5. Memahami struktur kode

HTML tersusun secara bertingkat. Sebuah elemen dapat berisi elemen lainnya. Misalnya, sebuah bagian dapat memuat judul dan paragraf. Gunakan indentasi supaya hubungan antarelemen mudah dilihat. Indentasi tidak selalu mengubah hasil halaman, tetapi sangat membantu ketika kode mulai panjang.

Atribut class juga penting. Class memberikan nama pada elemen sehingga nantinya dapat dipilih oleh CSS atau JavaScript. Contohnya adalah <div class="kartu">. Nama kartu itu dapat dipakai untuk memberikan latar, jarak, dan bentuk tertentu melalui CSS.

6. Kesalahan yang sering terjadi

Kesalahan pemula yang umum adalah salah mengetik nama tag, lupa menutup tag, menyimpan file dengan ekstensi yang salah, atau menggunakan nama gambar yang tidak sesuai. Jika halaman kosong, periksa apakah konten berada di dalam body. Jika tautan tidak bekerja, periksa nilai href. Jika gambar tidak muncul, periksa nama, ekstensi, huruf besar-kecil, dan lokasi gambar.

Belajar coding bukan berarti tidak boleh salah. Justru proses menemukan dan memperbaiki kesalahan adalah bagian penting dari belajar. Ubah satu bagian pada satu waktu, simpan file, kemudian muat ulang browser. Dengan cara ini kamu dapat melihat perubahan dan mengetahui bagian yang menyebabkan masalah.

7. Mengembangkan halaman pertama

Setelah halaman sederhana berhasil, tambahkan bagian tentang dirimu, daftar materi yang ingin dipelajari, dan tautan menuju halaman lain. Kamu juga dapat membuat file baru bernama tentang.html. Hubungkan kedua halaman menggunakan tautan relatif. Jika kedua file berada dalam folder yang sama, href="tentang.html" dapat digunakan untuk membuka halaman tersebut.

Jangan langsung membuat proyek terlalu besar. Buat satu halaman yang berfungsi terlebih dahulu. Setelah itu, rapikan struktur, perbaiki tulisan, dan pastikan tautan berfungsi. Simpan salinan sebelum melakukan perubahan besar. Kebiasaan sederhana ini membuat proses belajar lebih aman dan teratur.

Kesimpulan: HTML adalah fondasi struktur website. Pahami elemen, atribut, judul, paragraf, tautan, dan gambar sebelum melanjutkan ke desain.

Latihan Kode 1

  1. Buat file index.html.
  2. Tambahkan satu judul utama dan dua paragraf.
  3. Buat tautan ke website pilihanmu.
  4. Tambahkan gambar dengan atribut alt.
  5. Buka halaman di browser dan periksa hasilnya.
MODUL 2 • DESAIN WEBSITE

Kode 2: Belajar CSS dari Dasar

CSS adalah singkatan dari Cascading Style Sheets. CSS mengatur bagaimana elemen HTML ditampilkan. Dengan CSS, kamu dapat mengatur warna, ukuran teks, jarak, garis tepi, tata letak, dan tampilan responsif. Jika HTML adalah struktur rumah, CSS membantu membuat rumah tersebut nyaman dan menarik.

1. Cara kerja CSS

Aturan CSS memiliki selector, properti, dan nilai. Selector menentukan elemen yang akan dipilih. Properti menentukan bagian yang ingin diatur. Nilai menunjukkan pengaturan yang dipakai.

p {
  color: green;
  font-size: 18px;
}

Aturan tersebut memilih semua paragraf, mengubah warna teks menjadi hijau, dan mengatur ukuran tulisan menjadi 18 piksel. Titik koma memisahkan deklarasi. Kurung kurawal mengelompokkan aturan yang berlaku untuk selector tersebut.

2. Menghubungkan file CSS

Buat file bernama style.css pada folder yang sama dengan index.html. Kemudian masukkan tautan berikut di dalam elemen head HTML.

<link rel="stylesheet" href="style.css">

Setelah itu, tuliskan aturan CSS pada style.css. Memisahkan HTML dan CSS membuat proyek lebih rapi. Jika tampilan belum berubah, periksa nama file, lokasi file, tanda kurung, dan simpan perubahan.

3. Warna, font, dan jarak

CSS mendukung nama warna, kode heksadesimal, dan berbagai format warna. Contohnya #20c55e adalah warna hijau. Properti font-family mengatur jenis huruf, font-size mengatur ukuran, dan line-height mengatur jarak antarbaris. Pilih kombinasi yang mudah dibaca. Teks harus memiliki kontras yang cukup dengan latarnya.

Margin mengatur ruang di luar elemen. Padding mengatur ruang di antara isi dan tepi elemen. Border menambahkan garis tepi dan border-radius membulatkan sudut. Meskipun tampak sederhana, kombinasi jarak yang konsisten dapat membuat halaman lebih nyaman.

body {
  font-family: Arial, sans-serif;
  background: #f4f7f5;
  color: #17212b;
  margin: 0;
  line-height: 1.7;
}

.kartu {
  background: white;
  padding: 20px;
  border: 1px solid #dfe7e1;
  border-radius: 14px;
}

4. Mengenal class dan selector

Selector p memilih semua elemen paragraf. Selector .kartu memilih elemen yang memiliki class kartu. Sementara itu, selector #utama memilih elemen dengan id utama. Class dapat digunakan oleh banyak elemen, sedangkan ID sebaiknya unik dalam satu halaman.

Contohnya, HTML <div class="kartu">Materi OeR</div> akan menerima aturan .kartu di atas. Kamu dapat menggunakan beberapa class pada satu elemen untuk menggabungkan gaya. Gunakan nama class yang mudah dimengerti dan konsisten.

5. Mengatur tata letak

Flexbox membantu menyusun elemen dalam satu arah, misalnya menu navigasi atau tombol. Grid membantu menyusun baris dan kolom, misalnya kumpulan kartu. Keduanya lebih fleksibel daripada mengatur posisi setiap elemen dengan angka tetap.

.daftar-kartu {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}

@media (max-width: 700px) {
  .daftar-kartu {
    grid-template-columns: 1fr;
  }
}

Contoh ini menampilkan tiga kolom pada layar lebar. Ketika lebar layar 700 piksel atau kurang, kartu berubah menjadi satu kolom. Aturan seperti ini disebut media query dan menjadi bagian penting desain responsif.

6. Membuat website nyaman di ponsel

Pastikan halaman memiliki pengaturan viewport pada HTML. Gunakan ukuran fleksibel, hindari lebar tetap yang terlalu besar, dan uji tampilan di layar sempit. Tombol perlu mudah disentuh, teks mudah dibaca, dan gambar tidak boleh meluap keluar dari kontainer.

Desain responsif bukan hanya mengecilkan website. Kamu mungkin perlu mengubah urutan elemen, menyusun menu menjadi lebih sederhana, atau memberi jarak yang cukup. Periksa semua halaman, bukan hanya homepage, karena setiap halaman dapat memiliki kebutuhan tata letak berbeda.

7. Prinsip desain yang baik

Gunakan palet warna yang konsisten, judul yang jelas, dan jarak yang teratur. Jangan memenuhi halaman dengan terlalu banyak efek. Animasi dapat membantu memberi umpan balik, tetapi jangan sampai mengganggu pembaca. Pertimbangkan aksesibilitas, kontras, dan penggunaan keyboard agar website dapat digunakan lebih banyak orang.

Jika tampilan tidak sesuai harapan, periksa apakah selector cocok, apakah file CSS terhubung, dan apakah ada aturan lain yang menimpa. Ubah satu nilai, simpan, lalu muat ulang. Kebiasaan menguji secara bertahap membantu kamu menemukan penyebab masalah.

Kesimpulan: CSS mengatur tampilan website. Kuasai warna, jarak, selector, Grid, Flexbox, dan media query untuk membangun desain yang rapi serta responsif.

Latihan Kode 2

  1. Buat file style.css.
  2. Ubah warna latar dan warna judul.
  3. Buat sebuah kartu dengan sudut membulat.
  4. Susun tiga kartu memakai CSS Grid.
  5. Uji tampilannya di komputer dan ponsel.
MODUL 3 • INTERAKSI

Kode 3: Belajar JavaScript

JavaScript membuat website dapat merespons tindakan pengguna. Dengan JavaScript, tombol bisa mengubah teks, formulir dapat diperiksa, daftar dapat dicari, dan halaman bisa mengambil data dari layanan lain. Pelajari dasarnya sebelum membuat fitur yang kompleks.

1. Menambahkan JavaScript

JavaScript dapat ditulis langsung dalam tag script atau disimpan dalam file terpisah. Untuk proyek yang lebih rapi, buat file script.js dan hubungkan dengan HTML memakai kode berikut.

<script src="script.js" defer></script>

Atribut defer membuat skrip dijalankan setelah dokumen HTML selesai diproses. Pastikan file script.js berada di lokasi yang benar. Jika browser tidak menjalankan fitur, periksa Console untuk melihat apakah ada kesalahan JavaScript.

2. Variabel dan data

Variabel menyimpan nilai. Gunakan const jika variabel tidak perlu ditetapkan ulang dan let jika nilainya akan berubah. String adalah teks, number adalah angka, dan boolean adalah nilai benar atau salah.

const nama = "OeR";
let jumlah = 1;
jumlah = jumlah + 1;

console.log(nama);
console.log(jumlah);

console.log menampilkan nilai di Console browser. Fitur ini berguna untuk memeriksa proses program. Biasakan memakai nama variabel yang jelas dan hindari menaruh data sensitif di log atau kode publik.

3. Fungsi dan kondisi

Fungsi mengelompokkan instruksi yang dapat dipakai kembali. Fungsi dapat menerima parameter dan mengembalikan nilai. Kondisi if menjalankan kode berdasarkan suatu syarat.

function sapa(nama) {
  return "Halo, " + nama + "!";
}

const jam = 10;

if (jam < 12) {
  console.log(sapa("teman OeR"));
} else {
  console.log("Selamat siang!");
}

Fungsi sapa menerima nama lalu mengembalikan teks. Kondisi memilih pesan berdasarkan nilai jam. Kamu dapat mengembangkan contoh ini menjadi pesan sambutan atau fungsi lain yang sesuai kebutuhan.

4. Membuat tombol interaktif

JavaScript dapat memilih elemen HTML melalui DOM. Metode querySelector memilih elemen berdasarkan selector CSS. Kemudian addEventListener mendeteksi peristiwa seperti klik.

<button id="tombol">Klik saya</button>
<p id="pesan">Pesan awal</p>

<script>
const tombol = document.querySelector("#tombol");
const pesan = document.querySelector("#pesan");

tombol.addEventListener("click", function() {
  pesan.textContent = "Halo! Tombol berhasil diklik.";
});
</script>

Saat tombol ditekan, teks paragraf berubah. Pastikan ID pada HTML sesuai dengan selector. Jika elemen tidak ditemukan, periksa ejaan dan waktu skrip dijalankan. Gunakan tombol HTML asli agar pengguna keyboard juga dapat mengoperasikannya.

5. Membuat pencarian sederhana

Pencarian lokal dapat dibuat dengan membandingkan kata yang diketik dengan daftar materi yang tersedia. Contoh berikut mencari daftar kecil yang disimpan di dalam JavaScript.

const materi = [
  "HTML dasar",
  "CSS responsif",
  "JavaScript pemula"
];

function cariMateri(kata) {
  return materi.filter(item =>
    item.toLowerCase().includes(kata.toLowerCase())
  );
}

console.log(cariMateri("css"));

Metode filter membuat daftar hasil baru berdasarkan kondisi. toLowerCase membuat pencarian tidak membedakan huruf besar dan kecil. Contoh ini hanya mencari data yang tersedia di dalam program, bukan seluruh internet. Mesin pencari yang lebih besar memerlukan indeks, sumber data, dan sistem pembaruan.

6. Menghubungkan layanan dan menjaga keamanan

JavaScript dapat meminta data dari API menggunakan fetch. Permintaan jaringan bisa gagal, sehingga program perlu memeriksa respons dan menangani kesalahan. Tampilkan pesan yang jelas ketika data sedang dimuat atau tidak berhasil diambil.

Hal yang sangat penting: kode HTML dan JavaScript yang dikirim ke browser dapat dilihat pengunjung. Jangan menaruh password, kunci privat, atau rahasia database dalam file publik. Jika memakai Supabase, gunakan kunci yang memang ditujukan untuk penggunaan publik dan atur Row Level Security dengan benar. Kunci publik saja bukan pengganti aturan akses.

7. Memperbaiki kesalahan

Ketika tombol tidak berfungsi, periksa Console, nama variabel, selector, tanda kurung, dan urutan pemanggilan fungsi. Uji bagian kecil terlebih dahulu. Gunakan console.log untuk mengetahui nilai yang sedang diproses, lalu hapus log yang tidak diperlukan.

Jangan langsung menulis ulang semua kode karena satu fitur gagal. Simpan versi yang berfungsi dan ubah sedikit demi sedikit. Semakin teratur kode ditulis, semakin mudah kamu memperbaiki dan mengembangkan website pada masa mendatang.

Kesimpulan: JavaScript menambahkan interaksi dan logika. Pelajari variabel, fungsi, kondisi, DOM, peristiwa klik, serta keamanan dasar.

Latihan Kode 3

  1. Buat tombol yang mengubah isi paragraf.
  2. Buat fungsi yang menerima satu parameter.
  3. Buat daftar tiga materi.
  4. Tambahkan fungsi pencarian sederhana.
  5. Uji kode dan periksa pesan di Console.
MODUL 4 • PUBLIKASI WEBSITE

Kode 4: GitHub dan GitHub Pages

Setelah membuat website, langkah berikutnya adalah membagikannya secara online. GitHub dapat menyimpan kode proyek, sedangkan GitHub Pages dapat menerbitkan website statis dari repositori. Dengan memahami proses ini, kamu dapat mempublikasikan hasil belajar tanpa harus mengelola server sendiri.

1. Apa itu Git dan GitHub?

Git adalah sistem kontrol versi untuk mencatat perubahan berkas. GitHub adalah layanan daring yang menyediakan repositori Git dan alat kolaborasi. Repositori berisi file proyek serta riwayat perubahan. Kamu dapat memulai lewat browser, lalu mempelajari perintah Git ketika sudah lebih nyaman.

Susun proyek dengan rapi. Contohnya, index.html menjadi halaman utama, style.css menyimpan gaya, script.js menyimpan interaksi, dan folder images menyimpan gambar. Nama file dalam kode harus sesuai dengan file yang diunggah.

2. Membuat repositori

Masuk ke GitHub, buat repositori baru, lalu beri nama yang mudah dikenali. Tentukan visibilitas sesuai kebutuhan. Jika repositori publik, orang lain dapat melihat kode yang disimpan. Jangan mengunggah password, token akses, kunci rahasia, atau data pribadi.

Unggah berkas proyek melalui fitur penambahan file. Pastikan index.html berada di folder sumber yang sesuai. Beri pesan perubahan yang jelas, misalnya "Menambahkan halaman tutorial". Riwayat perubahan membantu kamu mengetahui apa yang telah diubah.

3. Mengaktifkan GitHub Pages

Buka repositori, masuk ke Settings, lalu cari Pages. Pilih sumber publikasi yang tersedia, misalnya branch utama dan folder root jika file website berada di folder tersebut. Simpan pengaturan dan tunggu proses penerbitan selesai. Gunakan URL yang diberikan GitHub untuk membuka website.

Jangan menebak URL akhir. Setelah publikasi berhasil, buka alamat yang ditampilkan GitHub. Uji halaman utama, navigasi, gambar, dan seluruh berkas CSS serta JavaScript. Periksa juga tampilannya di ponsel. Perubahan kadang memerlukan waktu sebelum terlihat di halaman online.

4. Memahami jalur berkas

Jalur berkas menentukan lokasi halaman atau aset yang akan dibuka. Jika tutorial.html berada dalam folder yang sama dengan index.html, tautan relatif href="index.html" dapat digunakan untuk kembali ke halaman utama.

Untuk situs proyek GitHub Pages, penggunaan jalur absolut seperti /index.html dapat bermasalah karena website mungkin berada di bawah nama repositori. Pilih jalur yang sesuai dengan struktur situs dan uji dari halaman online. Perhatikan huruf besar dan kecil dalam nama file karena server dapat membedakannya.

5. Memperbarui website dengan aman

Setiap kali mengunggah perubahan, periksa kembali website setelah publikasi selesai. Untuk perubahan besar, buat salinan atau cabang kerja terlebih dahulu. Jika halaman rusak, riwayat perubahan GitHub dapat membantu menemukan versi yang sebelumnya berfungsi.

Jika proyekmu sudah memiliki homepage dan integrasi Supabase, tambahkan halaman tutorial sebagai file terpisah. Jangan menghapus konfigurasi atau mengganti kode yang sudah berjalan hanya untuk menambahkan halaman baru. Uji halaman tutorial secara mandiri dan pastikan tautan kembali menuju homepage yang benar.

6. Keamanan dan privasi

GitHub Pages terutama digunakan untuk website statis. Website statis tidak otomatis menyediakan backend aman untuk menyimpan password atau mengatur seluruh hak akses pengguna. Jika membutuhkan akun dan database, gunakan layanan backend dengan aturan keamanan yang benar.

Jangan menyimpan rahasia di HTML, JavaScript, atau repositori publik. Jika menggunakan layanan database, pahami autentikasi dan kebijakan aksesnya. Periksa pula kode pihak ketiga sebelum memasangnya. Pastikan tautan jelas dan konten iklan dapat dibedakan dari isi utama.

7. Pemeriksaan sebelum membagikan website

Buka website dari browser lain atau perangkat lain. Klik semua tautan, periksa tampilan di ponsel, dan pastikan tidak ada gambar yang gagal dimuat. Periksa judul dan deskripsi halaman agar pengunjung memahami isinya. Pastikan teks contoh sudah diganti dengan konten yang memang ingin kamu tampilkan.

Mulailah dari website sederhana yang bekerja. Setelah itu, tambahkan halaman dan fitur secara bertahap. Simpan versi yang berfungsi, uji perubahan, dan catat hal yang dipelajari. Kebiasaan ini akan membantu proyek berkembang dengan lebih teratur.

Kesimpulan: GitHub menyimpan kode dan GitHub Pages dapat menerbitkan website statis. Selalu uji URL, jalur berkas, tampilan seluler, dan keamanan sebelum membagikan proyek.

Latihan Kode 4

  1. Buat repositori untuk proyek latihan.
  2. Unggah HTML, CSS, dan JavaScript.
  3. Aktifkan GitHub Pages melalui Settings.
  4. Buka URL yang diberikan GitHub.
  5. Perbarui satu teks lalu uji hasilnya secara online.
Selamat belajar! Kamu sudah mempelajari empat fondasi awal pengembangan website. Terus berlatih dengan membuat proyek kecil, misalnya halaman profil, daftar artikel, atau halaman tutorial milikmu sendiri.
